# Lily58 `caulk` layout plan

## Goals
- Improve coding ergonomics: strongest access to `{ } [ ] ( ) < > |` and `\` plus arrows on `H J K L`.
- Use inner thumb keys (current Space/Enter) as layer-taps: `LT(_NAV, KC_SPC)` and `LT(_SYM, KC_ENT)`.
- Keep number row on base, but add a left-hand number cluster on NAV: row above home row = `1–5`, home row = `6–0`.
- Add word behaviors/new QMK features while keeping layout simple and consistent.
- Tune home-row mods for comfort (Win/Linux shortcuts).

## Inputs confirmed
- OS shortcuts: Win/Linux (Ctrl/Alt).
- Thumbs: both inner thumbs are layer-taps.
- Modifiers: home-row mods with tuning.
- Numbers: base row stays; NAV left-hand cluster as described.

## Plan
1. **Layer model + thumb cluster**
   - Rename/repurpose layers as `_BASE`, `_NAV`, `_SYM`, `_ADJ` (keep tri-layer behavior for ADJ).
   - Set inner thumbs to `LT(_NAV, KC_SPC)` and `LT(_SYM, KC_ENT)`.
   - Keep outer thumbs for `KC_BSPC`, `KC_LGUI`, `KC_LALT` unless you want a change.

2. **Base layer (QWERTY + home-row mods)**
   - Apply HRM: `LCTL_T(KC_A)`, `LALT_T(KC_S)`, `LGUI_T(KC_D)`, `LSFT_T(KC_F)` and mirrored right-side mods (`RSFT_T(KC_J)`, `RGUI_T(KC_K)`, `RALT_T(KC_L)`, `RCTL_T(KC_SCLN)`).
   - If Alt is hard to reach, add a redundant Alt: one-shot (`OSM(MOD_LALT)`) on NAV/SYM or a dedicated thumb key.
   - Bump `TAPPING_TERM` from 100ms to a safer baseline (start ~180–220ms) and add per-key overrides if needed.

3. **NAV/NUM layer (left-thumb hold)**
   - Left-hand number cluster: row above home row = `1 2 3 4 5`; home row = `6 7 8 9 0`.
   - Right-hand navigation: arrows on `H J K L`, plus `HOME`, `END`, `PGUP`, `PGDN`, `DEL`.
   - Word navigation for Win/Linux: `Ctrl+Left/Right`, `Ctrl+Backspace` (as tap-code macros where needed).

4. **SYM layer (right-thumb hold)**
   - Prioritize `{ } [ ] ( ) < > | \` on the most reachable keys.
   - Cluster common coding operators: `= + - _ * / ! ? : ; @ #`.
   - Add `->`, `=>`, and `::` via short macros or combos if desired.

5. **Word behaviors + QMK features**
   - Enable `CAPS_WORD_ENABLE = yes` in `rules.mk`.
   - Add `CW_TOGG` key on SYM or ADJ.
   - Implement `caps_word_set_user()` so Caps Word continues through `_` and digits.
   - Optional: enable combos (`COMBO_ENABLE = yes`) for quick bracket pairs/arrow ops if you want them.

6. **OLED improvements (optional)**
   - Show layer name, Caps Word state, and active mods.
   - Remove keylog if firmware size becomes tight.
