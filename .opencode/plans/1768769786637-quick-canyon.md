# Plan: Trackpoint scroll direction + speed + sniping hold

## Goals
- Invert drag-scroll direction for Trackpoint by default.
- Slow drag-scroll to ~half speed via scroll buffer size.
- Make sniping mode on the Lily58 adjust layer hold-to-enable, release-to-disable.

## Files to change
- `users/caulk/caulk.c`
- `keyboards/lily58/keymaps/caulk/keymap.c`

## Implementation steps
1. Update Lily58 adjust layer to use hold sniping mode.
   - Replace `HK_S_MODE_T` with `HK_S_MODE` in `_ADJ` layer.

2. Invert drag-scroll direction for Trackpoint only.
   - In `hk_process_scroll`, compute a local `invert` flag.
   - If `pointer_state->drag_scroll` and `pointer_state->pointer_kind == POINTER_KIND_TRACKPOINT`, flip `invert` before applying it to `h`/`v`.
   - Keep existing `scroll_direction_inverted` behavior for non-trackpoint devices and non-drag-scroll cases.

3. Slow scroll by increasing the Trackpoint scroll buffer size default.
   - In `hk_configure_trackpoint_common`, change `pointer_scroll_buffer_size` from `5` to `10`.

4. Ensure existing EEPROM settings pick up the new default without manual reset.
   - Bump `hk_eeprom_config.version` from `100` to `101` in `eeconfig_init_user`.
   - In `keyboard_post_init_user`, after `deserialize_eeconfig_to_state`, detect `version == 100` and:
     - For any trackpoint pointer with `pointer_scroll_buffer_size == 5`, set it to `10`.
     - Update `hk_eeprom_config.version` to `101` and persist via `write_eeconfig()`.

## Verification
- Build: `qmk compile -kb lily58 -km caulk`.
- Flash and verify:
  - On `_ADJ`, hold sniping key (formerly toggle) slows cursor only while held.
  - Drag-scroll direction is natural without manual inversion.
  - Scroll feels about half speed vs before.
